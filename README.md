# parsec-ig-assets

Public image host for ParSec Solutions' Instagram publishing.

The Instagram Graph API can only ingest images from public HTTPS URLs, so the rendered
carousel slides live here and are referenced by their `raw.githubusercontent.com` URL.

Everything in this repo is marketing material intended to be public. No credentials, no
client data. Source of truth for the designs is `D:\Antigravity\Parsec-IG-Launch\`.

Swap to a ParSec-owned Cloudinary account when convenient — then this repo can be deleted.
